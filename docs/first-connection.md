# 第一次把手机和电脑连上

手机上一次只做一件事。电脑上一条命令。

## 手机上的五步

1. **还没配对。** 一句话说明收藏先留在手机里。主按钮是「开始连接」。蓝牙备用是灰的，旁边写着「先连上电脑，再设置蓝牙备用。」
2. **等电脑。** 页面给出可以复制的一句话：`请运行 cat-diao 的 scripts\run.ps1 pair，它会自己找到这台手机。` 展开「怎么做」能看到 PowerShell 命令。发现失败时，同一页有本机地址、复制按钮和二维码。
3. **核对数字。** 大大的 6 位数字，主按钮「允许」，旁边「拒绝」。数字只出现在手机和电脑终端上。
4. **已连上。** 绿色，写出电脑名字和最近一次同步。这时才能设置蓝牙备用。
5. **还是连不上。** 三句原因：不在同一个 Wi-Fi；公司或访客网络不让设备互访，可以让手机开热点；电脑网络是「公用」，防火墙不会放行，要改成「专用」。主按钮是「再试一次」。

## 电脑上的一条命令

在技能目录运行：

```text
scripts\run.ps1 pair
```

没有别的参数时，它会等大约 60 秒，先查 mDNS（`_catdiao._tcp`），再发局域网广播。找到手机后，终端打印 6 位数字。和手机上的一样，再在手机上点「允许」。

直接运行 `python 手机直达.py pair` 时，没写 `--wait` 大约等 8 秒。`127.0.0.1` 不会被当成手机地址。

自动发现失败时：

```text
scripts\run.ps1 pair --address http://手机上的地址:8767
```

猫叼用来做看画面、点画面的真机验证。它不替代 ADB。
