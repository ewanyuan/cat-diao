# 第一次把手机和电脑连上

手机上一次只做一件事。人把一句话或二维码截图丢给电脑上的 AI 即可。命令和 IP 只在真的连不上之后出现。

## 手机上的一条直线

1. **首页，还没配对。** 先用一句话说明这件事有什么用：「手机上复制的东西，电脑上直接能用。」主按钮是「连接电脑」。收藏是次按钮。不再把 `run.ps1 pair` 写在首页。
2. **连接电脑。** 一句话：把下面这句话发给电脑上的 AI，让它从 GitHub 装好猫叼（需要 Python 3），并和手机连同一个 Wi-Fi。手机如果正在用流量、没网络、开着 VPN，或 Wi-Fi 还要登录，这一句就改成那一件事，按钮是「我已连好，再检查」。主按钮是「复制这句话」。次按钮是「改用二维码」。二维码内容就是手机地址 `http://IP:8767`。左上角是「退出引导」，不是含糊的「关闭」。
3. **正在等待电脑连接…** 写出已等了多少秒，并留出 6 位数字的位置。电脑连上后，同一个数字出现在这里，主按钮「允许」，旁边「拒绝」。离开手机去操作电脑再回来，还停在这一步。
4. **✓ 已连上。** 写出电脑名字。主按钮是「现在复制一句话试试」，这句话会发到电脑剪贴板。旁边是「完成」。
5. **还没连上。** 只有在已经试过，并且手机探测到一个原因，或健康网络上等了约 3 分钟仍没有电脑连过来时才出现。只写一件事和对应的做法：不在同一个网络、VPN 挡住、手机没在等待、电脑没连过来，或 6 位数字过期。命令、地址和二维码收在「帮助」里。地址单独一行，不会从中间断开。

## 电脑上的 AI 怎么接

收到短话 `用猫叼连上我这台手机`（可带 `：http://IP:8767`），或收到含该地址的二维码截图时：

1. 有地址 → 运行 `scripts\run.ps1 pair --address http://IP:8767`
2. 没有地址 → 先运行 `scripts\run.ps1 pair`（自动寻找约 20 秒）
3. 终端打印 6 位数字后，让用户在手机上点「允许」

## 帮助：自己在电脑上操作

只在手机已经判定连不上、用户打开「帮助」之后才给这条命令。在技能目录运行：

```text
scripts\run.ps1 pair
```

没有别的参数时，它会自动寻找约 20 秒：先试上次成功的地址，再查 mDNS（`_catdiao._tcp`）和局域网广播；仍未找到时，会在真实 Wi-Fi/以太网网卡所在网段并行扫描 TCP 8767，并用只读的 `/hello` 确认手机。找到手机后，终端打印 6 位数字。和手机上的一样，再在手机上点「允许」。

`--wait` 可缩短等待时间，最长约 20 秒。`127.0.0.1` 不会被当成手机地址。

自动发现失败时：

```text
scripts\run.ps1 pair --address http://手机上的地址:8767
```

猫叼用来做看画面、点画面的真机验证。它不替代 ADB。
