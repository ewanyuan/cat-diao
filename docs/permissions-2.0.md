# 猫叼 2.0 权限

收藏本身不需要额外权限。把文件或剪贴板发到电脑只需要网络。看画面、点画面需要「猫叼屏幕控制」。调节亮度需要「修改系统设置」。悬浮窗只用于悬浮猫，配对、收藏和屏幕控制都不用它。配对之后的设置里可以点「跳过」，不授予也能做完后面的步骤。以后仍可在「更多」里打开悬浮猫。

## 安卓的「受限设置」

从浏览器或文件管理器安装时，安卓 13 及以上会拦住屏幕控制。第一次打开应用时，猫叼会先带你到应用信息页。请点右上角 ⋯，选择「允许受限设置」，再回来打开「猫叼屏幕控制」。不同品牌的菜单位置可能不一样。

## 省电和开机

请允许猫叼忽略电池优化，否则系统会在后台关掉连接。首页每天最多提醒一次。点「去允许」选允许即可。

部分手机还要单独打开自启动 / 后台：

- 小米：自启动和省电策略
- 华为：应用启动管理
- **OPPO（本机）：**应用管理 → 猫叼 → 耗电管理，打开「允许完全后台行为」和「允许自动启动」。只关电池优化往往不够，息屏后 8767 仍可能被杀。
- vivo：后台高耗电
- 三星：不受限制

应用已用前台服务、WakeLock、WifiLock，并在被划掉或销毁后尝试闹钟拉起。第一次配对的等待页和核对数字页还会保持屏幕常亮；这段时间里，即使进程被收掉、令牌还没保存，也会把 8767 再拉起来。这些仍挡不住 OPPO 的强省电策略——上面两项必须手开。

猫叼会在开机后尝试恢复连接。若系统仍拦住后台，按上面的说明打开自启动。

通知里可以随时「暂停遥控」或「恢复遥控」。暂停时，看画面、点画面、发文件、剪贴板、壁纸、音量和打开应用会停；收藏和心跳仍可用。首页上可以直接撤销与这台电脑的连接。
