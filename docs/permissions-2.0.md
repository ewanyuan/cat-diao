# 猫叼 2.0 权限

收藏本身不需要额外权限。把文件或剪贴板发到电脑只需要网络。看画面、点画面需要「猫叼屏幕控制」。调节亮度需要「修改系统设置」。悬浮窗是可选的，不开也能收藏。

## 安卓的「受限设置」

从浏览器或文件管理器安装时，安卓 13 及以上会拦住屏幕控制。第一次打开应用时，猫叼会先带你到应用信息页。请点右上角 ⋯，选择「允许受限设置」，再回来打开「猫叼屏幕控制」。不同品牌的菜单位置可能不一样。

## 省电和开机

请允许猫叼忽略电池优化，否则系统会在后台关掉连接。部分手机还要单独打开自启动：

- 小米：自启动和省电策略
- 华为：应用启动管理
- OPPO：耗电保护
- vivo：后台高耗电
- 三星：不受限制

猫叼会在开机后尝试恢复连接。若系统仍拦住后台，按上面的说明打开自启动。

通知里可以随时「暂停遥控」或「恢复遥控」。暂停时，看画面、点画面、发文件、剪贴板、壁纸、音量和打开应用会停；收藏和心跳仍可用。首页上可以直接撤销与这台电脑的连接。
