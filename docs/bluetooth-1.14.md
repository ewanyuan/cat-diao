# 猫叼 1.14：换网络后找回小窝

首次把手机和电脑连接到同一个 Wi-Fi，在手机上点「开始连接」，电脑运行 `run.ps1 pair`，完成配对。还没配对时，蓝牙备用不会打开，页面写明要先连上电脑。配对完成后，在「已连上」里点「设置蓝牙备用连接」，允许附近设备，并在系统蓝牙设置中将手机与电脑配对一次。电脑上的猫叼接收需要保持运行。

此后蓝牙会交换两台设备的当前地址。Wi-Fi 能互通时优先使用 Wi-Fi；不能互通时，蓝牙可以补送收藏中的链接和文字。文件、屏幕控制和直接发送剪贴板仍需要 Wi-Fi。更换 IP 无需重新配对猫叼。

首页只保留连接结果和下一步：

- 「Wi-Fi 已连接」：可以正常传送。
- 「蓝牙已连接」：收藏可以送达，传文件请连同一个 Wi-Fi。
- 「正在找小窝」：本次检查最多 10 秒。
- 「还没找到小窝」：确认电脑接收已开启，也可以设置蓝牙备用连接。
- 「收藏还在手机里」：这次还没送达，猫叼会自动再试。

连接地址和二维码留在「开始连接」页，不占首页。未授权蓝牙时仍可使用 Wi-Fi。没连上电脑之前，不会出现点下去只有一句提示、没有下一步的蓝牙按钮。

蓝牙使用 Windows 原生 RFCOMM 和安卓安全 RFCOMM 服务，不增加电脑依赖。系统蓝牙配对之外，还核验猫叼现有配对令牌。双向挑战、逐消息签名和序号用于拒绝其他设备及旧回执；收藏落盘后才回传确认，断线重试沿用同一个收藏 ID。蓝牙不会发送令牌原文。

已完成自动化检查：协议签名与分帧、中文传输、超时、伪造配对、重复回执、断线重试去重、数据库确认，以及已有连接和文件传输回归。2026-10-07 已在当前 OPPO Android 12 手机与 Windows 电脑上完成真实蓝牙握手、原配对校验，并确认 Wi-Fi 和蓝牙后台通路均连接成功。关闭 Wi-Fi 后的实际收藏补送仍需单独验收。
